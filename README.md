# DV-Prep — منصة تجهيز وإدارة بيانات متقدمي برنامج الهجرة العشوائية الأمريكي (DV)
### DV Applicant Preparation & Management Platform

منصة ويب آمنة، احترافية، ومتعددة اللغات (عربي / إنجليزي) مصممة خصيصاً للمتقدمين البالغين ومكاتب الخدمات الإدارية لتجهيز وتدقيق ومطابقة بيانات ووثائق وصور المتقدمين لبرنامج تأشيرة التنوع (Diversity Visa) وفق المتطلبات الرسمية لوزارة الخارجية الأمريكية، تمهيداً للإدخال اليدوي الدقيق والآمن في الموقع الحكومي الرسمي (`travel.state.gov`).

---

## 1. المبادئ الأخلاقية والقانونية الصارمة (Compliance & Ethics)

1. **لا تدعي المنصة نهائياً ضمان القبول أو الفوز أو اعتماد الصورة**: وزارة الخارجية الأمريكية هي الجهة الوحيدة المخولة بالاختيار والقبول.
2. **منصة تجهيز وإدارة وليست بديلاً عن التسجيل الرسمي**: لا تقوم المنصة بتقديم الطلبات تلقائياً أو تجاوز اختبارات التحقق (CAPTCHA)، بل توفر وضع "تجهيز الإدخال الرسمي" مع أدوات نسخ الحقول بنقرة واحدة لتسهيل التعبئة الشخصية في الموقع الرسمي.
3. **عدم تعديل الملامح أو التجميل بالذكاء الاصطناعي (Strict No AI Face Beautification)**: تقتصر معالجة الصور الرقمية على التحقق الفني (المقاسات 600×600 بكسل، الحجم أقل من 240KB، عمق الألوان sRGB، فحص توسيط الوجه ونسبة ارتفاع الرأس ومستوى العينين) مع الحفاظ على ملامح الوجه ولون البشرة والشعر كما هي في الأصل تماماً.
4. **قواعد السنوات الديناميكية (`DVProgramYear`)**: إدارة قواعد وشروط كل سنة برنامج دون الحاجة لإعادة كتابة الكود.
5. **تشفير البيانات الحساسة (AES-256-GCM)**: تشفير أرقام جوازات السفر، الهويات الوطنية، وأرقام التأكيد (`Confirmation Numbers`).
6. **سجل تدقيق غير قابل للتعديل (`Audit Logs`)**: توثيق كافة العمليات، مراجعات المستندات، والتأكيدات لضمان أقصى درجات الشفافية والمسؤولية القانونية.

## 3. حزمة التقنيات (Tech Stack)

- **Frontend**: Next.js 14/15 (App Router), TypeScript, Tailwind CSS, Lucide Icons, Bilingual RTL (العربية) & LTR (English).
- **Backend**: Python 3.12+, FastAPI, SQLAlchemy 2 (Async), Pydantic V2, Alembic, OpenCV, Pillow.
- **Workers & Queues**: Celery + Redis لعمليات الـ OCR والفحص الفني للصور وتوليد التقارير.
- **Database**: PostgreSQL 16+ (مع دعم التشفير المتماثل AES-256 للحقول الحساسة) مع إمكانية التشغيل السلس على SQLite في بيئات التطوير والاختبار.
- **Storage**: MinIO (محلياً) أو AWS S3 في بيئة الإنتاج مع روابط موقعة مؤقتة (Presigned URLs).
- **Security**: تشفير كلمات المرور باستخدام PBKDF2-HMAC-SHA256، مصادقة JWT، حماية CSRF، وصلاحيات RBAC متعددة المستويات.

## 4. خطوات التشغيل (Getting Started)

### الخيار أ: التشغيل المتكامل عبر Docker Compose (البيئة الموصى بها للإنتاج)

1. تأكد من تثبيت Docker و Docker Compose على جهازك.
2. قم بإنشاء ملف `.env` اعتماداً على النموذج:
   ```bash
   cp .env.example .env
   ```
3. تشغيل الحاويات بالكامل في الخلفية:
   ```bash
   docker compose up --build -d
   ```
4. الوصول إلى المنظومة:
   - **الواجهة الأمامية للمتقدم**: `http://localhost` أو `http://localhost:3000`
   - **توثيق الواجهة البرمجية (Swagger UI)**: `http://localhost/docs` أو `http://localhost:8000/docs`
   - **لوحة تحكم MinIO التخزينية**: `http://localhost:9001`

---

### الخيار ب: التشغيل المحلي في بيئة التطوير (Local Development)

#### 1. تشغيل الـ Backend (FastAPI):
```bash
cd backend
python -m venv venv
# في نظام Windows PowerShell:
.\venv\Scripts\Activate.ps1

pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```
- يعمل الخادم تلقائياً على `http://localhost:8000`، وينشئ قاعدة البيانات والبيانات الأولية (Seed Data) تلقائياً عند أول تشغيل.

#### 2. تشغيل الـ Frontend (Next.js):
```bash
cd frontend
npm.cmd install
npm.cmd run dev
```
- يعمل تطبيق الويب على `http://localhost:3000` مع دعم التحويل اللحظي بين العربية والإنجليزية وتغيير اتجاه الصفحة RTL/LTR.

## 5. مسار الاستخدام الرئيسي (User Journey)

1. **البيانات الشخصية (Personal Details)**: تعبئة البيانات بالكامل ومطابقتها مع جواز السفر.
2. **أفراد الأسرة (Family Members)**: إدراج الزوج/الزوجة والأبناء المؤهلين مع إشعار تحذيري صارم لمنع إغفال أي طفل أو زوج.
3. **المستندات وقراءة الـ OCR**: قراءة شريط جواز السفر (MRZ) واستخراج الحقول مع درجات الثقة وأزرار التأكيد البشري.
4. **التقاط وفحص صورة اللوتري (DV Photo)**: فحص أبعاد 600×600 بكسل، الحجم أقل من 240KB، عدم وجود تشويش (Laplacian Variance)، وتمركز الرأس دون أي تعديل لملامح الوجه.
5. **شروط الأهلية (Eligibility)**: توثيق المؤهل التعليمي أو الخبرة المهنية المؤهلة.
6. **محرك التناقضات (Consistency Engine)**: اكتشاف التعارضات بين تواريخ الميلاد، الأسماء، ووثائق أفراد الأسرة.
7. **المراجعة والإقرار القانوني (Final Review)**: مراجعة شاملة وإقرار كتابي صريح بصحة واكتمال البيانات.
8. **وضع تجهيز الإدخال الرسمي (Official Submission Prep)**: عرض الحقول بنفس تسلسل استمارة وزارة الخارجية مع أزرار نسخ سريعة، ثم حفظ وتشفير رقم التأكيد الرسمي (Confirmation Number) في الخزنة الآمنة.
